# 🚀 Interactive 3D Portfolio | Rawan Ehab

An immersive, 3D interactive personal portfolio built to showcase projects, skills, and experience. Designed with a sleek terminal aesthetic, this portfolio uses modern web technologies to deliver a dynamic and engaging user experience.

---

## ✨ Features

- **🎮 3D Interactive Models:** Seamlessly integrated 3D elements that you can interact with, built using Three.js and React Three Fiber.
- **💻 Terminal Aesthetic:** A dynamic "About Me" section featuring a retro terminal with simulated typing effects and command outputs.
- **📱 Glassmorphism UI:** Beautiful, semi-transparent frosted glass panels for contact links and information.
- **🥚 Hidden Easter Eggs:** Can you find the secret theme? (Hint: standard cheat codes might just work here).
- **⚡ High Performance:** Optimized animations and 3D rendering using GSAP and Vite.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **3D Graphics:** Three.js, React Three Fiber (@react-three/fiber), React Three Drei (@react-three/drei)
- **Animations:** GSAP (GreenSock), React Spring
- **Styling:** Custom CSS with Glassmorphism and Matrix Background effects
- **Analytics:** Vercel Analytics
